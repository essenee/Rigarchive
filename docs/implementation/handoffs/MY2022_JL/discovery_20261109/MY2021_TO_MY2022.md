# MY2021 to MY2022 observed manufacturer offering changes

Created: 2026-11-09
Status: Proposed

Baseline: unchanged MY2021 `preliminary_factory_offerings.json`, its source/page
refs, and the completed 73-consumer milestone. Compare the **74-row discovery**
(including RHD) with the **56-row MY2022 guide union**, rather than comparing a
consumer count to an all-scope count. The linked JSON/CSV has every old/new row
and source locator; no canonical database comparison or mutation is performed.

## Continuing and new observations

55 body/model/trim/engine combinations continue in the observed evidence,
including one RHD row. All six engine-code families continue to appear: ERC, ERG,
EC1, EXJ, ECX and ESG. This is code/availability continuity, not approval to reuse
MY2021 five-field conclusions or proof that codes denote identical engines across
years.

One guide-row combination is newly observed: JLJL74 High Tide, ERG/DFT, QOP 25D,
first observed 2022-02-10 p2, with package content pp3–4. The Stellantis release
of 2022-02-07 separately establishes Jeep Beach as the first 500 High Tide
vehicles with edition decals. Jeep Beach's independent identity and ordering-code
relationship remain unadjudicated, so it does not add a mechanically invented row.

19 MY2021-only combinations belong to the 80th Anniversary Edition, Freedom and
Islander: eight two-door and eleven four-door rows. They are absent from all 18
retained MY2022 guides. This supports an **observed catalogue removal**, not a
claim of proven production discontinuation on a specific day or worldwide.

## Nomenclature

MY2022 JLJL74 and JLJP74 both use the column label **Altitude**. The comparison
aligns these to MY2021 Sport Altitude and Sahara Altitude only for comparison,
using their distinct manufacturer model sections. This is not MY2022 canonical
trim approval. JLXP74 uses High Altitude within the Sahara 4xe section; preserve
that context and do not merge it with conventional JLJP74 High Altitude.

## Transmission and revision changes

MY2022 October p2 lists ERC/DFT for the four two-door Sport-family columns, while
the MY2021 observed union contains only ERC/DEM for those four rows. MY2022 October
four-door p8 also adds an observed ERC/DFT alternative for Sahara-section Altitude
compared with that MY2021 row. These are new **transmission observations**, not
additional canonical identities. Their subsequent omissions/reappearances are
recorded exactly in `revision_comparison.json`.

Two-door ERC automatic QOPs 24B/K/S/W appear in October; all disappear in November;
24W returns in January. Four-door 24L in Sport and 24G/L in Sahara occur in October
and are subsequently omitted. Do not discard these early-supported alternatives
because the technical overview or final guides simplify the availability picture.

## Package restrictions and canonical effects

MY2021 four-door August guide p16 restricts Rubicon Xtreme Recon AGB to ERG,
explicitly excluding 22R/23R/26R. MY2022 February pp6 and 16 explicitly allow ERG
or EC1, excluding relevant manual/ERC/diesel QOPs; p6 includes Willys Sport/Willys
columns and High Tide standard package context. This demonstrates changed package
applicability, not a new engine combination or permission to multiply baselines.
The unchanged MY2021 source inventory resolves that baseline source hash/page.

MY2022 February four-door p15 lists 4.88 axle DMS; two-door and technical FA p2
also retain axle evidence. Detailed restriction lineage is retained in package
pages, not encoded as a new compatibility evaluator. No claim of complete package
rule normalization is made by this discovery.

High Tide/Jeep Beach taxonomy may affect canonical scope after owner review.
Transmission, axle, tire, paint and ordinary package differences remain subordinate
to identity under ADR-0010. No new engine family is established by the observed
MY2022 code union. Exact availability windows and uncertain classification values
remain the review questions in `UNRESOLVED_AND_NEXT_STAGE.md`.
