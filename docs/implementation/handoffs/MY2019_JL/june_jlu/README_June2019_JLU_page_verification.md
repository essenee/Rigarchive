# MY2019 JL manufacturer evidence checkpoint — 4-door June 2019

Verified from the published text of Jeep's June 4, 2019 U.S. four-door order guide, pages 2, 5, and 9: 13 marketed trim/powertrain combinations across seven four-door trims.

Source: https://www.jlwranglerforums.com/forum/attachments/4-door-6-4-19-pdf.190918/?force-system-browser=1

The Moab table on page 5 lists ERC quick-order code 24M and no EC3 Moab quick-order code. This establishes absence from the June edition, not necessarily all editions.

The `23*`/`24*` alternatives are transmission selections within the same canonical ERC powertrain. `28*` corresponds to EC3. The same 23L/24L/28L package codes appear under different parent model codes for Sport Altitude and Sahara Altitude; model code context is mandatory.
